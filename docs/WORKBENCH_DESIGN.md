# 金融证据工作台设计

2026-10-21 用户授权思考后直接实施，三小时循环，以 leon1111-wgl 的 GitHub 为入口。

## 完整纵向场景

选择公司与年度，执行英文证据搜索、三个财务指标之一或本地模型辅助问题。展示证据原文、页种、哈希、财务输入、公式、工具执行记录。用户逐条记录核对结果、添加备注并导出 JSON；刷新可恢复当前浏览器的草稿。核对记录不是签名，也不把 synthetic_fixture 改成人工核验财报。

## 运行方式

公开 GitHub Pages：由 Python 构建受限语料包，浏览器执行 BM25 与 BigInt 有理数／half-even 运算。没有凭据、模型请求或公共上传。
本地：python -m finevidence.server，一套 HTML/JS；loopback Python 服务直接调用现有 workflow，临时索引与来源重查；环境变量配置 OpenAI-compatible 模型。

模型最多 4 次调用，单次超时 15 秒、总预算 45 秒、输出上限 256 tokens；最多一次格式纠正，无网络自动重试。结果只来自允许的工具。每次显示模型标识、调用数、用量与状态；不展示／保存模型内部思维内容。公开服务部署、组织认证和持久审计不在本地回环服务的安全声明中。

服务拒绝外部 Host／Origin、缺失 CSRF、超大 body、未知路径和未知参数；模型 endpoint 来自操作者环境，不来自网页。不开启 CORS、不提供任意 URL/SQL/文件工具、不读取私人资料。HTTPS 校验与禁止重定向保证密钥不会跟随跳转。

## 界面

中性背景、系统字体、24px 页面标题、14–16px 正文，表格数字右对齐。桌面结果／原文双栏，窄屏顺序流。原文可键盘打开，焦点清晰。所有可见操作真实执行；无宣传 hero、渐变或装饰性卡片。

## 验收

Python 原 155 项保持；增量覆盖真实 HTTP 服务、请求边界、工具协议与失败预算。JS 使用 Python 输出核对检索排序与六项财务结果。真实浏览器测桌面／窄屏、键盘、加载／空白／错误／重试、核对／导出／恢复。授权后执行有界晨涧 API 集成并记录实际 tokens，不把 stub 记录混入真实结果。公开发布核对 SHA、CI 与线上文件字节；本地只留说明和证据。
